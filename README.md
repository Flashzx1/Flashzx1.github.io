# Flashzx1 Portfolio

Персональный сайт-портфолио с проектами BookingFlow, ServiceFlow и LeadFlowBot.

## Локальный просмотр

Откройте <code>index.html</code> в браузере или запустите локальный сервер:

~~~powershell
python -m http.server 8080
~~~

Сайт будет доступен по адресу <code>http://127.0.0.1:8080</code>.
